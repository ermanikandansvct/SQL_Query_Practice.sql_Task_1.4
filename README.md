# Task 1.4 – SQL Query Practice

## Overview
This task focuses on practicing SQL queries using a sample student database.

## Topics Covered

- Table joins using JOIN

- Maximum and minimum values using MAX() and MIN()
- Sorting using ORDER BY
- Subqueries

The database contains student details and subject marks for:
- Maths
- Python
- DBMS
